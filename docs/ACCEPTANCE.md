# Preview evidence

The TypeScript, AUI and Windows Go development builds completed locally. Desktop/mobile screens were rendered in Chrome against isolated NTFS data. My Maps renders real OpenStreetMap tiles and returns Photon place results. Stale reverse lookup responses no longer replace later selections, dropped pins retain their exact coordinates, and the map restores its overlays after Settings. Mobile tabs retain their size above scrolling search results.

No physical camera/microphone quality, Internet NAT traversal, 32-person capacity, clean Windows host, exhaustive feature/security audit or full Google parity claim is made. See README for precise capabilities and remaining gaps. Release and installed-runtime receipts are recorded separately when completed.
