# Downloaded map data

Map packs are obtained only when the server owner requests a plan and installation.
The application archive includes code and dependency licences, not a planet dataset.

- OpenStreetMap contributors: https://www.openstreetmap.org/copyright . Data is
  available under the Open Database Licence (ODbL1.0).
- Protomaps basemap: https://docs.protomaps.com/basemaps/downloads . Its map tiles
  are an ODbL Produced Work based on OpenStreetMap, with required OSM attribution.
  The chosen source URL/version is retained in the installed pack metadata.
- GeoNames towns: https://download.geonames.org/export/dump/readme.txt . The
  cities15000 extract is licensed CC BY4.0, https://creativecommons.org/licenses/by/4.0/ .
- GeoNames UK postcodes: https://download.geonames.org/export/zip/readme.txt . CC BY4.0.
  Contains Royal Mail data; Royal Mail copyright and database right2022.

Attribution is shown on the map and in the download screen. The local geographic
index is derived from the selected map bounds, names and GeoNames records. This
app offers no warranty of source completeness, accuracy or current opening times.
Dependency licence texts for Leaflet, Protomaps and Go/browser libraries are included
in THIRD-PARTY-LICENSES.txt in the release ZIP.
